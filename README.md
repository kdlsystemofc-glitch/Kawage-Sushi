# Kawage Sushi — Landing Page

Landing page premium para o **Kawage Sushi**, restaurante japonês em São Bernardo do Campo, SP.

## Stack

- HTML5 + CSS3 + JavaScript vanilla (sem dependências)
- Google Fonts (Cormorant Garamond + DM Sans)
- Vídeo hero em autoplay/loop com composição por scroll
- Totalmente responsivo (mobile-first)

## Estrutura

```
index.html        → página principal
imagens/          → fotos do restaurante
video/
  hero.mp4        → vídeo do hero
vercel.json       → cache headers para Vercel
```

## Deploy

Conecte este repositório no [Vercel](https://vercel.com) como **Static Site**.  
Não é necessário nenhum build step — o Vercel serve o `index.html` diretamente.
